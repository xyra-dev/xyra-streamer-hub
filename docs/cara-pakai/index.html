Ringkasan

Urutan lengkapnya begini

  1. Daftar & ambil tokenDaftar sebagai streamer lewat Discord. Setelah di-approve, minta token dengan perintah /token — token tampil sekali, jangan dibagikan.
  2. Install APKDownload dari halaman Download. Izinkan "Install unknown apps" untuk browser-mu, lalu saat Play Protect muncul pilih Scan app → Install.
  3. Atur izin appIzinkan notifikasi, lalu di pengaturan battery pilih No restrictions — penting supaya app nggak dimatikan saat di background (terutama MIUI/HyperOS).
  4. Tempel token, Start saat liveTempel token sekali, akun TikTok-mu terkunci di app. Saat kamu live di TikTok, tekan Start dan tunggu status live.
  5. Connect di gameMasuk ke game Roblox, buka panel streamer, tekan Connect. Gift yang masuk langsung tampil. Selesai live? Tekan Stop di app.
Urutan penting: Start dulu di app, baru Connect di game. Kalau dibalik, game akan bilang kamu belum live. Error lain? Cek halaman FAQ.
