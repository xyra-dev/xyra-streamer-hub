FAQ

Pertanyaan umum

Kumpulan masalah yang paling sering muncul, plus jawabannya.

Bagaimana cara tahu nama gift atau jumlah koin untuk atur trigger efek di game?
Di panel streamer dalam game, kamu bisa atur efek apa yang jalan saat gift tertentu masuk. Buka Katalog Gift TikTok — cari nama gift, lihat jumlah koinnya, lalu tempel nama atau angka koin itu di panel streamer. Nama gift di panel pakai huruf kecil bahasa Inggris, persis seperti yang tampil di katalog.
Apa itu Xyra Streamer Hub?
App Android untuk streamer TikTok mobile murni. Saat kamu live, app ini menangkap gift yang masuk dan meneruskannya ke game Roblox secara otomatis — semua jalan dari HP-mu, tanpa PC.
Kenapa muncul peringatan Play Protect / "app tidak dikenal"?
Karena APK-nya diinstall di luar Play Store, Android selalu menampilkan peringatan itu untuk app apa pun. Tekan Scan app → tunggu sebentar → Install. APK resmi hanya dibagikan lewat halaman Download ini (GitHub Releases resmi Xyra Studio) — jangan pernah install APK dari sumber lain.
Gagal install / "App not installed"
Cek dua hal: HP-mu harus arm64-v8a dan Android 10 ke atas. Kalau tetap gagal, hapus dulu versi lama yang terinstall, pastikan file APK-nya selesai ter-download penuh (±29,6 MB), lalu install ulang. Masih gagal? Coba download ulang dari halaman Download.
Token ditolak / invalid
Token hanya tampil sekali saat dibuat lewat perintah /token di Discord. Kalau hilang atau ditolak, minta token baru lewat /token — token lama otomatis mati begitu yang baru dibuat. Pastikan tidak ada spasi di awal/akhir saat menempelkannya.
App-nya mati sendiri saat di background (HP Xiaomi/MIUI/HyperOS)
MIUI dan HyperOS agresif mematikan app di background. Solusinya: (1) Pengaturan battery app → pilih No restrictions, (2) aktifkan Autostart, (3) buka layar recent apps lalu kunci app-nya (klik ikon gembok atau tarik ke bawah). Ini langkah wajib di langkah ke-3 panduan Cara Pakai.
Kenapa harus tekan Start dulu, baru Connect di game?
Saat kamu tekan Connect, game mengecek ke server: "apakah app streamer ini sedang Start?" Kalau app belum Start, jawabannya belum live dan kamu nggak bisa tersambung. Jadi urutannya selalu: Start di app → Connect di game.
Gift masuk di app, tapi nggak muncul di game?
Kemungkinan game belum Connect saat gift datang — gift yang masuk sebelum game tersambung tidak diantrekan. Pastikan status di game sudah live/tersambung, lalu minta penonton kirim gift lagi. Cek juga app masih Start (bukan Stop/Idle) dan HP nggak mematikan app-nya di background.
Apakah app ini butuh password TikTok-ku?
Tidak. App tidak pernah minta password TikTok. Yang dipakai adalah token khusus per streamer yang dibuat admin lewat Discord — token itu bisa dicabut kapan saja, dan hanya mengizinkan app membaca event gift dari akunmu saat live.
Apakah ini app resmi TikTok atau Roblox?
Bukan. Xyra Streamer Hub adalah proyek independen oleh Xyra Studio dan tidak berafiliasi, didukung, maupun disetujui oleh TikTok atau Roblox. Gunakan sesuai aturan platform masing-masing.
